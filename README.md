# Personal Portfolio Website

A personal portfolio website built with **HTML, CSS and Vanilla JavaScript** to showcase my projects, products and professional journey.

🔗 [sanodmendis.pages.dev](https://sanodmendis.pages.dev/)

---

## Features

- **Responsive Design** – Works seamlessly across desktop and mobile
- **Project Showcase** – Highlighting professional, freelance and academic work
- **Product Pages** – Dedicated product details with descriptions and images
- **Interactive UI** – Smooth navigation and animations using Vanilla JS
- **Custom Styling** – Modular CSS for different pages
- **Lightweight & Fast** – No frameworks, minimal dependencies

---

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
